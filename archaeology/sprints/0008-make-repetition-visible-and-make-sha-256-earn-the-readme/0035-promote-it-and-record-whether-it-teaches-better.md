# Promote it, and record whether it teaches better

## Objective

Promote the film, and record what the round actually taught.

Two separable things. The README promotion is a packaging job with one real constraint: there is
no hosted attachment for the Order video, so the ordering the promotion would prefer is not
available and a placeholder must not pretend otherwise.

The archaeology has to answer the question this round exists to settle — not *does the feature
work* but **is the explanation materially clearer because of it**. An impressive field that
teaches nothing is a failure with good production values, and saying so is the only thing that
keeps the archaeology worth reading.
