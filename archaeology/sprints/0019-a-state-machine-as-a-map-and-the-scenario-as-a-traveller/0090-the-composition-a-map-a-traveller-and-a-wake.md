# The composition: a map, a traveller, and a wake

## Objective

The composition: draw a machine as a map with a traveller on it, so that a paused frame answers
where the machine is, how it got there, and what else could happen — without the narration.

## Acceptance criteria

- The whole topology is drawn from the first frame at a neutral, legible baseline. Nothing is
  attenuated for not having happened yet, and nothing disappears for not being taken.
- Occupancy is persistent, exclusive and released: exactly one state carries it, it is the
  strongest signal on the frame, and the state that had it returns to ordinary topology rather
  than being dimmed as though it were dead.
- A traversal is visible as a traversal: the traveller crosses the selected edge, and the edge
  it crossed keeps a quiet wake afterwards, recent traversal stronger than old.
- A revisit re-ignites the existing node in place. A repeated transition reads as a new
  occurrence and the frame says how many times it has been taken. A self-transition visibly
  fires while occupancy stays put.
- A screen-space readout names the current state and the route that reached it, elided from the
  left when the route is long. Derived from the beats; nothing authored.
- Nothing in the composition declares a state final, accepting, or terminal.
